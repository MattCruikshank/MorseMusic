# Morse Music

Turn any text into Morse code sheet music for flute, cello or piano, and play it back with the current note highlighted.

**Live:** https://mattcruikshank.github.io/MorseMusic/

- Dots and dashes become rhythm; several melody styles (chord arpeggios, dot-up/dash-down contour, scale runs, letter tones) pick the notes.
- Flute (treble clef), cello (bass clef) or piano (grand staff, with a left-hand accompaniment).
- Choice of key, full or pentatonic scale, time signature and tempo. Settings are saved in the URL.

Plain HTML, CSS and JavaScript — just open `index.html`. Notation is drawn with [VexFlow](https://www.vexflow.com) 4.2.3 (MIT, see `lib/VEXFLOW-LICENSE`).
